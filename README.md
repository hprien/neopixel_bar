At my friends house we installed [neopixels](https://en.wikipedia.org/wiki/Adafruit_Industries#NeoPixel) in his home bar.

# ESP program code
The code in `esp_source` is written with VSCode Extension PlatformIO.
It enables an [ESP](https://www.espressif.com/en/products/socs/esp32) to receive [DMX](https://en.wikipedia.org/wiki/DMX512) signals and contol a neopixel strip accordingly.

# Animation Simulator
In The folder `neopixel_simulator` you'll find a demo of the visual effect (don't forget to turn on master_dim in the demo).
